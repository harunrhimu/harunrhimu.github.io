SECTION 1: PREREQUISITES (Install These First)
============================================================

Before you can run this project, install the following on your PC:

1. Node.js (v18 or higher)

   - During install, check "Add to PATH"

2. npm (comes with Node.js)
   - Verify: npm --version

3. Git (optional, for version control)
   - Download: https://git-scm.com/
   - Verify: git --version

4. A Code Editor (recommended: VS Code)
   - Download: https://code.visualstudio.com/

SECTION 3: FIRST-TIME SETUP (New PC)
============================================================

Step 1: Copy the project folder to your new PC
   - Copy the entire "portfolio" folder

Step 2: Open a terminal/command prompt
   - Navigate to the portfolio folder:
     cd path/to/portfolio

Step 3: Install all dependencies
   - Run this ONE command:
     npm install
   - This reads package.json and installs everything
   - Wait until it finishes (may take 1-2 minutes)
   - A "node_modules" folder will be created

Step 4: Verify installation
   - You should see no red error messages
   - If you see warnings (yellow), those are usually OK

============================================================

This is for editing and previewing changes locally.

SECTION 6: DEPLOYING TO A LIVE WEBSITE
============================================================

--- Option A: Netlify (Recommended - Free & Easy) ---

1. Go to https://www.netlify.com/ and sign up
2. Click "Add new site" > "Deploy manually"
3. Drag and drop the "dist" folder
4. Your site is live! Netlify gives you a URL
5. To use harunrhimu.com:
   - Go to Domain settings > Add custom domain
   - Follow DNS instructions to point your domain

--- Option B: Vercel (Also Free) ---

1. Go to https://vercel.com/ and sign up
2. Install Vercel CLI: npm install -g vercel
3. In the portfolio folder, run: vercel
4. Follow the prompts
5. Add custom domain in Vercel dashboard

--- Option C: Traditional Hosting (cPanel, etc.) ---

1. Run: npm run build
2. Upload ALL contents of the "dist" folder to your
   hosting's public_html or www directory
3. IMPORTANT: For SPA routing to work, you need a
   redirect rule. Create a file called "_redirects"
   in the dist folder with this content:
     /*    /index.html   200
   OR if using Apache, create .htaccess in dist:
     <IfModule mod_rewrite.c>
       RewriteEngine On
       RewriteBase /
       RewriteRule ^index\.html$ - [L]
       RewriteCond %{REQUEST_FILENAME} !-f
       RewriteCond %{REQUEST_FILENAME} !-d
       RewriteRule . /index.html [L]
     </IfModule>

--- Option D: GitHub Pages ---

1. Run: npm run build
2. Push the dist folder to a gh-pages branch
3. Or use the "gh-pages" npm package:
   npm install -D gh-pages
   Add to package.json scripts: "deploy": "gh-pages -d dist"
   Run: npm run deploy

SECTION 10: TROUBLESHOOTING
============================================================

Problem: "npm install" fails
  - Make sure Node.js is installed (node --version)
  - Delete node_modules folder and package-lock.json
  - Run: npm install

Problem: "npm run dev" shows errors
  - Delete node_modules/.vite folder
  - Restart: npm run dev

Problem: Page shows blank or 404 after deployment
  - You need SPA redirect rules (see Section 6, Option C)
  - Every URL must redirect to index.html

Problem: Contact form doesn't send emails
  - Check EmailJS credentials in ContactPage.jsx
  - Make sure you're using the correct Service ID,
    Template ID, and Public Key from emailjs.com

Problem: SEO titles not changing per page
  - Make sure react-helmet-async is version 2.x (not 3.x)
  - Check: npm list react-helmet-async
  - If v3, downgrade: npm install react-helmet-async@2.0.5

Problem: Images not showing after build
  - Images in public/ folder are served from root (/)
  - Use paths like "/harunrhimu.jpg" not "./harunrhimu.jpg"

Problem: Loading spinner shows briefly when navigating
  - This is normal! Pages are lazy-loaded (code splitting)
  - Each page only loads when you visit it for the first time
  - This makes the initial page load much faster

SECTION 11: PERFORMANCE OPTIMIZATIONS (Already Applied)
============================================================

These optimizations are already built into the project.
No action needed -- this is for your reference.

1. ROUTE CODE SPLITTING (App.jsx)
   - All pages use React.lazy() + Suspense
   - Only the visited page's code is loaded, not all pages
   - Reduces initial JavaScript bundle by ~30%

2. IMAGE LAZY LOADING
   - All below-fold images have loading="lazy"
   - Browser only loads images when they scroll into view
   - Hero profile image loads immediately (above fold)

3. SEO (Search Engine Optimization)
   - Per-page meta titles, descriptions, canonical URLs
   - Open Graph tags for social media sharing
   - Twitter Card tags
   - JSON-LD structured data (Person, Service, FAQ, Article)
   - robots.txt and sitemap.xml for Google crawling
   - Breadcrumb navigation on detail pages
   - Keyword-optimized H1 tags on every page

4. CUSTOM 404 PAGE
   - Invalid URLs show a branded error page
   - Includes navigation back to Home and Case Studies
   - Has noindex meta tag so Google won't index it

5. MINIMAL BUNDLE
   - No unused dependencies
   - Only essential packages installed

SECTION 12: HOW TO ADD/EDIT CONTENT
============================================================

All content is stored in data files. Edit these to update
your portfolio without touching any component code:

--- Case Studies ---
File: src/data/caseStudies.js
Each entry has: slug, title, client, industry, image,
challenge, solution, details, results, tags, videoUrl

--- Blog Posts ---
File: src/data/blog.js
Each entry has: slug, title, category, date, dateISO,
readTime, excerpt, image, content (array of paragraphs)

--- Services ---
File: src/data/services.js
Each entry has: title, longDescription, deliverables,
process, iconPath, accent

--- FAQ ---
File: src/data/faqs.js
Each entry has: q (question), a (answer)

--- Skills & Certifications ---
File: src/data/skills.js
Contains: certifications, experiences, education,
onlineCourses arrays

--- Personal Info to Update ---
- Name/bio: src/components/Hero.jsx, Footer.jsx
- Profile photo: public/harunrhimu.jpg (replace this file)
- Social links: Hero.jsx, Footer.jsx
- Contact email: src/pages/ContactPage.jsx

When adding new case studies or blog posts, also update
public/sitemap.xml with the new URLs for better SEO.
